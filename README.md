# Abhitesh Shukla — Engineering Portfolio

A static, responsive portfolio using verified content from Abhitesh's GitHub profile and the four featured repositories. Includes discipline filters, accessible native-dialog case studies, and a saved light/dark theme preference.

Live portfolio: https://snow-warrior07.github.io/

Run `node serve.mjs` and open the printed local URL. The deployable site is in `dist/`.

GitHub Pages publishes `dist/` through `.github/workflows/pages.yml` whenever changes are pushed to `main`. The workflow validates local assets, section and case-study references, and JavaScript syntax before deploying. It can also be run manually from the repository's Actions tab. No dependency installation or build step is required.

Project images are existing renders, plots and screenshots from the user's repositories. The two learning-pipeline diagrams illustrate the documented architectures. No employment, education, clinical outcomes or real-world business savings have been invented.
