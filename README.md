# Abhitesh Shukla — Engineering Portfolio

A static, responsive portfolio using Abhitesh's resume, confirmed coursework, GitHub profile and four featured repositories. Includes education, internships, institute leadership, technical skills, selected engineering and Business Studies courses, contact links, and the downloadable source resume. Project filters, accessible native-dialog case studies, and a saved light/dark theme preference complete the site.

Live portfolio: https://snow-warrior07.github.io/

Run `node serve.mjs` and open the printed local URL. The deployable site is in `dist/`.

GitHub Pages publishes `dist/` through `.github/workflows/pages.yml` whenever changes are pushed to `main`. The workflow validates local assets, section and case-study references, and JavaScript syntax before deploying. It can also be run manually from the repository's Actions tab. No dependency installation or build step is required.

Project images are existing renders, plots and screenshots from the user's repositories. The two learning-pipeline diagrams illustrate the documented architectures. Education, internship descriptions, leadership roles and contact details come from the supplied resume. Coursework comes from that resume and the supplied course tables; attendance at all five Business Studies courses was explicitly confirmed. The site does not claim IIM Mumbai enrollment or prerequisite completion. No employment outcomes, clinical outcomes or real-world business savings have been invented.
